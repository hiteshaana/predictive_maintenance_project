# Predictive Maintenance Using Machine Learning & MLOps

## 1. Project Overview

This project develops an end-to-end Predictive Maintenance solution using Machine Learning and MLOps practices to identify engine operating conditions that may require maintenance.

Industrial equipment failures can result in unplanned downtime, production losses, emergency maintenance costs and reduced equipment availability. The objective of this project is to use operational sensor data to identify engine conditions requiring maintenance and support proactive, condition-based maintenance decisions.

The solution combines:

- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Feature engineering
- Multiple machine learning models
- Hyperparameter tuning using GridSearchCV
- Model evaluation
- MLflow experiment tracking
- Hugging Face Dataset Hub
- Hugging Face Model Hub
- Streamlit deployment
- Docker containerization
- GitHub Actions CI/CD

---

## 2. Business Problem

Unexpected equipment failures can significantly impact manufacturing operations through:

- Unplanned production downtime
- Increased maintenance costs
- Emergency repairs
- Reduced equipment availability
- Difficulty identifying machines approaching failure
- Underutilization of operational sensor data

Traditional reactive and fixed-schedule preventive maintenance approaches may not fully utilize the operational information generated by industrial sensors.

This project addresses the problem by developing a machine learning based classification solution that predicts engine condition from operational sensor readings.

## 4. Dataset

The project uses industrial engine sensor data containing operational measurements such as:

- Engine RPM
- Lubrication Oil Pressure
- Fuel Pressure
- Coolant Pressure
- Lubrication Oil Temperature
- Coolant Temperature

### Target Variable

`Engine_Condition`

The target represents the engine condition classification used by the predictive maintenance model.

### Dataset Management

The original dataset and processed train/test datasets are managed through the Hugging Face Dataset Hub.

Repository:

`hiteshsharma/predictive_maintenance-dataset`

The training pipeline loads the training and testing datasets directly from Hugging Face to improve reproducibility and demonstrate an MLOps-oriented data workflow.

## 5. Exploratory Data Analysis

The project performs comprehensive EDA covering:

### 5.1 Data Overview

The analysis includes:

- Dataset dimensions
- Data types
- Duplicate records
- Missing-value analysis
- Descriptive statistics

### 5.2 Target Distribution

The distribution of `Engine_Condition` is analyzed to understand class representation and identify potential class imbalance.

### 5.3 Univariate Analysis

Each predictor is analyzed individually using:

- Histograms
- KDE distributions
- Boxplots
- Mean
- Median
- Standard deviation
- Skewness
- IQR-based potential outlier analysis

Feature-level observations and business insights are generated for the sensor variables.

### 5.4 Bivariate Analysis

Bivariate analysis includes:

- Predictor vs Engine Condition boxplots
- Class-wise mean comparisons
- Numerical scatter plots
- Pearson correlation analysis

The analysis helps identify sensor variables that may contain predictive information about engine condition.

### 5.5 Multivariate Analysis

Multivariate analysis includes:

- Correlation heatmap
- Sensor pairplot
- Relationships between multiple operational variables
- Analysis of feature redundancy and combined operating patterns

The project recognizes that engine health is influenced by multiple interacting operational parameters rather than a single sensor measurement.
